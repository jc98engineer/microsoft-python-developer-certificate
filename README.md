# Microsoft Python Developer Certificate Portfolio

This repository documents my learning journey through the Microsoft Python Developer Certificate on Coursera.

The goal of this repository is not only to complete the certificate, but to transform each course into practical, professional, and portfolio-ready Python projects focused on data analysis, automation, web development, and industrial analytics.

## Learning Objectives

- Strengthen Python programming fundamentals.
- Build data analysis and visualization projects using pandas, NumPy, and Matplotlib.
- Automate repetitive data workflows with Python scripts.
- Develop simple web applications and APIs using Flask.
- Apply advanced Python techniques such as decorators, generators, context managers, and testing.
- Build professional projects using Git, GitHub, documentation, and reproducible environments.
